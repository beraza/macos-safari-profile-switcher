# Safari Profile Switcher

Приложение для строки меню macOS: переключает окна Safari между профилями, переносит вкладки между профилями и открывает ссылки из других приложений в нужном профиле.

## Возможности

**Переключение профиля (по умолчанию ⌥⇥).**
- Каждое нажатие показывает следующее окно текущего профиля. Когда окна профиля закончились, показывается окно другого профиля.
- Если окон другого профиля нет, открывается новое окно этого профиля через меню Safari «Файл → Новое окно». Новое окно встаёт на место текущего, в том числе в полноэкранном режиме.
- Окно, где открыта только стартовая страница, закрывается. Это можно отключить в настройках.
- Если удерживать ⌥ дольше задержки или нажать ⇥ ещё раз, появится переключатель (HUD), как у ⌘⇥. В нём видны профили или окна. ⇥ и ⌥→ выбирают следующий элемент, ⌥⇧⇥ предыдущий, ⌥⎋ отменяет выбор. Отпустите ⌥, чтобы подтвердить, или щёлкните по нужному элементу.

**Вкладки.**
- **⌥⇧⇥** переносит текущую вкладку в другой профиль. Если для сайта есть правило, вкладка уходит в профиль из правила. Переносится только URL: история и cookies остаются в старом профиле. Есть режим «копировать». После переноса в меню появляется пункт «Всегда открывать сайт в профиле…».
- **⌥⇧↑** выносит вкладку в отдельное окно того же профиля. **⌥⇧↓** возвращает её в окно, откуда она пришла. В обоих случаях история вкладки сохраняется.

**Строка меню.**
- Значок показывает активный профиль: первую букву или свой текст для каждого профиля.
- В меню перечислены окна, сгруппированные по профилям. Щелчок по окну выводит его вперёд. У каждого профиля есть пункт «Новое окно».

**Ссылки.** Приложение можно сделать браузером по умолчанию: «Настройки → Ссылки». Тогда ссылки из других приложений открываются в профиле, который выбирают правила.
- Правило задаётся по сайту и, при желании, по приложению-источнику. `example.com` срабатывает вместе с поддоменами, `*.example.com` только для поддоменов, `github.com/org` задаёт путь. Приложение указывается как bundle id, например `com.tinyspeck.slackmacgap` для Slack.
- Если ни одно правило не подошло, ссылка открывается в профиле по умолчанию или появляется меню выбора профиля. Чтобы выбрать профиль вручную, удерживайте ⌥ при клике по ссылке. Если в этом меню удерживать ⌥, выбор запомнится как правило.
- Ссылки-обёртки (Outlook Safe Links, Facebook, Google, VK) разворачиваются, а `utm_*`, `fbclid` и подобные параметры удаляются.

Все шорткаты настраиваются и отключаются на вкладке «Шорткаты». Если назначить сочетание, которое уже занято, действия поменяются сочетаниями. Шорткаты для Safari регистрируются, только пока Safari на переднем плане, поэтому в остальных приложениях эти сочетания свободны. Что делает ⌥⇥ вне Safari, задаётся в настройках.

Интерфейс есть на английском и русском, язык берётся из системы.

Профиль окна определяется по заголовку: Safari называет окна `«Профиль» — «Заголовок страницы»`.

## Сборка и установка

Нужны macOS 15+ и Xcode (или Command Line Tools со Swift 6).

```bash
scripts/build-app.sh --install
```

Без `--install` приложение собирается в `build/SafariProfileSwitcher.app`.

Чтобы macOS не забывала разрешение Универсального доступа после каждой пересборки, один раз создайте локальный сертификат подписи:

```bash
scripts/create-signing-cert.sh
```

При первой подписи этим сертификатом macOS спросит доступ к ключу в связке ключей. Выберите «Разрешить всегда», иначе `codesign` будет ждать ответа при каждой сборке.

## Разрешения

1. **Универсальный доступ** нужен, чтобы нажимать пункты меню Safari (новое окно профиля, вынос вкладки), поднимать окна и следить за активным окном.
2. **Автоматизация → Safari** нужна, чтобы читать и менять окна и вкладки.

Статус обоих разрешений виден в «Настройки → Разрешения». Там же есть кнопка «Сохранить диагностику Safari»: она пишет окна и меню Safari в `~/Library/Logs/SafariProfileSwitcher/diagnostics.txt`.

## Разработка

```bash
swift test
```

```bash
swift build && .build/debug/SafariProfileSwitcher --self-test
```

- `Sources/SwitcherCore` — вся логика решений, покрытая тестами: переключение, перенос вкладок, выбор окна для возврата, HUD, правила ссылок, конфликты шорткатов.
- `Sources/SafariProfileSwitcher` — само приложение:
  - хоткеи через Carbon;
  - Safari через одну заранее скомпилированную библиотеку AppleScript-обработчиков и Accessibility;
  - строка меню, HUD, настройки;
  - String Catalog в `Resources`.
- `--self-test` проверяет AppleScript-часть на запущенном Safari. Он создаёт свои временные окна и закрывает их, а ваши окна не трогает. Также проверяются настройки, регистрация хоткеев, меню, маршрутизация ссылок и HUD. Если задать `SPSW_SNAPSHOT_DIR`, самопроверка сохранит PNG с HUD и вкладками настроек. Части, которым нужен Универсальный доступ, проверяются только в установленном приложении.
